# ZapMarketing IA

Aplicativo web no estilo WhatsApp com uma assistente de IA para apoiar ações de marketing da empresa.

## Recursos

- Interface de chat inspirada no WhatsApp.
- IA com respostas rápidas para campanhas, conteúdo e vendas.
- Bloco lateral com ideias de campanhas e KPIs simulados.
- Layout responsivo para desktop e mobile.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Digite seu objetivo no campo de mensagem.
3. Clique em **Gerar nova ideia** para obter sugestões de campanha.

## Estrutura

- `index.html`: estrutura da aplicação.
- `styles.css`: estilo visual (tema WhatsApp).
- `app.js`: lógica do chat e respostas da IA.
